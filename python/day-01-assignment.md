26.
Consider:

name = "Rahul"
Name = "Amit"
Are name and Name treated as the same name in Python? Explain why.


Answer: No.

Python is case-sensitive, so name and Name are treated as two different variable names.

Example:

name = "Rahul"
Name = "Amit"

What is wrong with using names such as x, y, and z everywhere in a large program? Is using short names always wrong?

D. Practical Problems

Answer: They are not descriptive, so they make a large program harder to understand and maintain.

Is using short names always wrong? No. Short names are fine when their meaning is obvious, such as i in a loop.
