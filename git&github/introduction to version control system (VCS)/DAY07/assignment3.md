Assignment 3: Practical – Push Using Method 2
Objective: Perform the complete flow of creating a local repository and pushing it to GitHub.

Tasks:

Create a new folder on your computer named Day7_Practice.
Inside it, create a file about.txt and write your name and one Git command you learned.
Perform the following commands in order:
git init
git add .
git status
git commit -m "Added about file"
git log --oneline
git remote add origin <your-github-repo-url>
git branch -M main
git push -u origin main
Verify that the file appears on GitHub.
